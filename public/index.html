LUCID Help

Clarity Through the Chaos.

How to Analyze

Paste a suspicious email, message, URL, security alert, log, or code, or upload a supported file or image. Choose ShieldMe or TIQ, then select Analyze.

ShieldMe

Designed for everyday users. ShieldMe explains whether submitted evidence appears Safe, Suspicious, or Dangerous and provides clear recommended next steps.

TIQ

Designed for security analysts. TIQ provides technical classification, severity, key indicators, MITRE ATT&CK context, technical reasoning, confidence, and recommended security or SOC actions.

File & Image Uploads

LUCID supports readable content from PDF, DOCX, CSV, TXT, log files, supported source-code files, screenshots, security-alert images, and Wireshark/network-capture screenshots.

File Analysis Safety

Uploaded files are treated as evidence and are not executed. LUCID safely extracts and analyzes content it can read. Unsupported, unreadable, corrupted, or encrypted files may return Inconclusive.

Important File Limitation

LUCID analyzes the content it can read from a file. A result does not guarantee that the entire file is safe. A malicious-content value of not detected means malicious indicators were not identified in the available content, not that the complete file has been proven safe.

My Checks

My Checks contains your ShieldMe analysis history. It lets you review previous everyday-security checks, verdicts, explanations, and guidance.

TIQ Dashboard

The Dashboard provides a consolidated analyst view of incidents, severity, status, attack patterns, and incident trends. Select an incident row to open its detailed investigation view.

Incident Correlation

When the exact same evidence is analyzed in ShieldMe and TIQ, LUCID can correlate the analyses into one incident instead of creating unnecessary duplicate incidents.

24-Hour Correlation Rule

Matching evidence is correlated only when the existing matching incident is Open or In Progress and was created within the previous 24 hours. Resolved or older incidents are not reused; a later analysis creates a new incident.

Analyst Workflow

Open an incident from the TIQ Dashboard, review the technical analysis, investigate the evidence, record what was done in Analyst Action / Resolution Notes, then update the incident status.

Resolving Incidents

LUCID requires investigation or action notes before an incident can be marked Resolved. Saved notes and status remain available when the incident is reopened.

Risk Register

TIQ's Risk Register lets analysts record and manage security risks using a description, category, priority, and status.

Switching Modes

ShieldMe provides plain-language security guidance and My Checks. TIQ provides technical analysis plus analyst tools including the Dashboard and Risk Register.

Clear Results

Select Clear Results to remove the current analysis from the screen and return to the Analyzer. This does not delete saved incidents, My Checks history, resolution notes, or Risk Register entries.

What LUCID Does Not Do

LUCID does not execute uploaded files, perform sandbox or dynamic malware analysis, inspect behavior hidden inside encrypted or unreadable content, or guarantee that a file, account, device, or system is safe.

When Additional Verification Is Needed

High-risk or uncertain findings should be validated with appropriate endpoint, network, sandbox, malware-reputation, SIEM, EDR, or forensic tools when required by the investigation.

Privacy & Secrets

Avoid submitting passwords, authentication tokens, API secrets, private keys, or other sensitive credentials. Submit only the evidence necessary for the security analysis.

AI Disclaimer

AI-generated analysis can make mistakes. Verify important security decisions. LUCID is a security-analysis assistant and its results should be considered alongside other available evidence and appropriate security tools.
